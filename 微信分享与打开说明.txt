LUMERA · SnapFlow 电商视觉内容生成平台｜分享与打开说明

一、直接在线使用（推荐）
打开线上部署地址（如 ChatGPT Site），浏览器直接使用，无需安装。

二、本地运行完整项目
环境要求：Node.js 22.13 或更高版本。

1. 解压本压缩包。
2. 在解压目录打开终端。
3. 执行：npm install
4. 复制 .env.example 为 .env.local，填入你的 API 地址和密钥。
5. 执行：npm run dev
6. 浏览器打开终端显示的本地网址，通常是 http://localhost:3000/

三、核心功能
1. 商品净图：商品原图 → 标准电商白底图。
2. 真人穿搭：人物基准图 + 白底商品图 → 同人物真人穿搭图。
3. 动态商拍：多套穿搭图 + 视频模板 → 响指循环换装视频。
4. 历史记录：查看、下载、删除生成过的图片和视频（/history）。

四、运营后台（/admin）
- 服务接入：配置 4 个智能体的 API 地址、密钥和模型。
- 生成策略：自定义每个智能体的系统提示词。
- 视频灵感库：上传视频模板，设置模板编号和参考图数量。

五、文件说明
- app：页面和 API 路由
- lib：智能体定义、提示词和第三方平台适配
- public：参考图片与视频
- agents：智能体配置和提示词
- API接入说明.md：接口接入文档

安全提醒：本压缩包不包含创建者的 API Key。请勿通过微信发送任何完整 API Key、密码或账号验证码。
